INTERVIEW QUEST v2.2.0 — GITHUB UPLOAD GUIDE (HINDI/HINGLISH)

Is update mein UI ko simple kiya gaya hai: 4 main tabs, less-congested Home, Learn path, collapsible Question Bank filters, clearer question page, bigger text/buttons aur updated service-worker cache. Question bank aur local progress logic preserve ki gayi hai.

1. Interview-Quest-v2.2.0-GitHub-Upload.zip download karke extract karo.
2. GitHub par apna repository kholo: https://github.com/Vikas915577/Interview-Quest
3. Add file > Upload files par jao. ZIP ke ANDAR ki files select karo; ZIP file ko directly upload mat karna.
4. Root mein index.html, app.js, style.css, sw.js, manifest.webmanifest, icon.svg, questions.json, sources.json aur docs/ reports honi chahiye.
5. Same-name core files ko replace karo. Agar tumne kisi file mein apne changes kiye hain, pehle backup ya compare kar lo.
6. Commit changes.
7. Settings > Pages mein main branch aur /(root) verify karo. Publish URL kholo.
8. Site khulne ke baad refresh karo; cache refresh ke liye app version v2.2.0 hai. Agar purana UI rahe, pehle browser ko close/open aur hard refresh karo. Progress backup export karne se pehle site storage clear mat karna.
9. Check: Today > Start practice; Learn > choose topic > Start path > Next; Questions > search/filter; Mock > finish; Progress; More > Export backup.

IMPORTANT:
- GitHub Pages par app ko static website ke roop mein host kiya jaata hai.
- Progress current browser/device mein local save hoti hai; export/import backup use karo.
- Voice typing support browser/device par depend karta hai. Voice icon kaam na kare toh Android keyboard microphone use kar sakte ho.
- ChatGPT alag tab mein khulta hai. Full AI grading is free static build ka part nahi hai.
- Automated local tests pass karna hosted, real phone testing ka replacement nahi hai. Actual URL phone par check karna zaroori hai.
