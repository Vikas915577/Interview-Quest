PHONE SE UPLOAD STEPS
1. Download and extract Interview-Quest-v2.1.3-GitHub-Upload.zip.
2. Open https://github.com/Vikas915577/Interview-Quest and select Add file → Upload files (Chrome Desktop site can help).
3. Upload ALL files from this ZIP's root into the repository root, choosing Replace when asked. Do not upload the ZIP itself.
4. Make one commit to main. Make sure index.html, app.js, style.css, sw.js, questions.json and sources.json are in repository root.
5. Open Settings → Pages and confirm branch main / root. Visit the published URL.
6. Refresh the site. If the old load-error remains, first export backup if possible, then clear this site's data in Chrome and reopen. The new service worker clears old Interview Quest caches on activation.
